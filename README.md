本分支是由 https://github.com/moeru-ai/airi Fork而来,并按照个人偏好增加了许多新功能

1.Chess:中国象棋和国际象棋,棋子皮肤均为公开免费SVG,并使用开源模型本地计算,由Airi根据你的水平来选择下一步的招

2.记忆模块(beta):现在对话中只有很少轮的context进入缓存,其余的均归档可查询,同时加入了自选模型整理,智能选择长期/短期记忆并打上标签储存,对话中的模型也可管理记忆

3.桌面捕获:Airi现在可通过工具实现桌面捕获与控制鼠标/键盘

4.对话框渲染优化

5.存储优化:有时候老端口没有完全关闭,新的Airi就会跑到新端口重新建立档案,这里将端口强制固定到了初始端口,不会出现打开后重新配置丢失所有文件的情况

6.QQ集成,可以通过Napcat的ws客户端/服务端连接至QQ实现QQ消息回复

7.MC模块上下文优化(激进/beta):普通的事件不会传送到大脑,只有对话等主动事件才会消耗token
